# The Bellwood Aspirant — a Cultist-Simulator vertical slice for the Chorus text engine.
#
# Hollowmere: a fog-bound cathedral town where the bells ring one note too many
# and the fog keeps whatever the bells say. The player is WREN, a restorer of
# old ledgers with three foundations (VIGOR, WITS, YEARNING), no silver, two
# thin books, and a rite she has no business owning. The design doc for this
# slice is docs/plans/v0.6-cs-slice.md; the verified mechanics it authorizes are
# docs/reverse/cultist-simulator.md §2/§3/§5/§6. This file is PHASE B of the
# authoring: the full card inventory, the verbs and their slots, the decks, the
# endings, the card-borne machines, and Phase A's 39 recipes (the doc's §4
# groups Work & silver, the Turning, the eight weathers, market & streets) are
# joined by 34 more — Study & the lore ladder, Dream & the moods, and the
# Bellwood crossing. 73 of the 102 recipes are in; the TALK and USE_ON verbs
# still carry only their defaults, and the later phase lands them. The lore
# ladder, the desire chain and the door are already playable end to end:
# books grind to fragments, pairs combine upward, the first lone 6+ read
# yields THE_WAY_THROUGH, and the Bellwood pays rung-6/18 lore into the hand.
#
#   WORK      — labor and the clerk's post    (silver, the labor rolls, the bootstrap)
#   WAIT      — the wheel                     (THE_TURNING: the season engine, self-rechaining)
#   STUDY     — the lore ladder               (radiance and hush, three rungs each, the Way)
#   DREAM     — moods and the desire chain    (the MOODS deck, promise → vow → hunger)
#   TALK      — the congregation              (Mercy Hale: acquaintance → believer → disciple)
#   MANSUS    — the Bellwood crossing         (one door, one deck, no reset)
#   USE_ON    — the Lifted Lamp               (one rite: one summon, the desire ascension)
#   ACQUIRE   — the flea market               (the skeleton key, tin candles, grey salve)
#   TRAVEL_TO /
#   LOCATE_AT — the two streets the slice owns
#
# Text policy (owner, 2026-10-16): CS strings may be quoted for this
# engine-validation slice (open-source, non-commercial, game owned); the
# Hollowmere frame stays. Mechanics and numbers remain dossier-governed
# facts, and the slice's own naming is this repo's: the principles (RADIANCE,
# HUSH), the door (the Bellwood), the rite (the Lifted Lamp), the summon (the
# Tolling Guest), the desire (the Hunger of Heights), the people and every
# sentence are the repo's own.
#
# Two engine laws this file obeys (both verified by run, 2026-10-15):
#   1. REPLACE's successor resolves strictly inside trigger bodies — a never-
#      alive prototype there bricks every commit on the verb — so every
#      card-borne transform is DESTROY + SPAWN + SET. Recipes may REPLACE
#      into prototypes freely (the mint carries the prototype's aspects).
#   2. Predicates read aspects and attrs, never names: every card a recipe
#      must recognize inside a bound role carries a one-level marker aspect
#      (weary, dim, pale, dread, rapture, ease, mending, book, fever, frail,
#      toll, ...). WAKEFULNESS and GLIMMER stay bare — nothing binds them.
# The market's stock is finite: what the trestles hold at the start is all
# Hollowmere has (a restock trigger would have to mint a declared entity,
# which the engine refuses — the brick this file once shipped).
#
# The wheel is the slice's engine-from-a-single-spark. The first completion that
# binds a job card (VIGOR, the clerk's post) fires its `on complete job` clause:
# spawn THE_TURNING if absent, then RUN "time.turn" cross-verb (§9.48 — CS's
# job→needs induce). time.turn drains one silver, draws a weather from the
# SEASONS deck, and hands the cycle to that weather's recipe; every weather ends
# by running time.turn again — the dossier's needs → discardseason → drawseason
# → needs loop, as RUN chains (§9.47). Later bootstraps find THE_TURNING alive,
# spawn nothing, and are suppressed exactly as CS's are.
#
# Time scale: 1 CS second → 1 engine minute (a 60 s action is the 1 h verb
# duration; a 60 s season cycle is the 1 h WAIT window; the summon's 180 s is
# the guest's 3 h). Chances are CS-exact: 30% labor and induction rolls, the
# 90/70/30 cult-business convention, 70% hunt and cure rolls, 90% ascension
# (Grand-rite 10% failure), the 3-mark death rules.
#
# seed: 1837 — chosen so the pinned win path's BELLWOOD draws run THE_LOST_BELL
# first (draw 1) and THE_BELL_HEART by draw 6, closing radiance 24 as 18 + 6;
# the dice calibrate in the authoring phases (docs/plans/v0.6-cs-slice.md §8).

# ── what can be done ─────────────────────────────────────────────────────
# the slice's nine verbs. Slot queries use the §9.49 alternation wherever CS's
# any-of slots demanded it (WORK's entry, the rite's invocation). Recipes are
# the authoring phases' work (docs/plans/v0.6-cs-slice.md §4 — 102 of them);

verbs:
  WORK:
    # CS's one big any-of entry slot, as alternation: a foundation (intact or
    # drained — the marker aspects), the guest (uncanny labor), the
    # frailty (ruined labor), or a clerk's post (the bench — G1's work.post
    # and work.senior work it). Pay is recipe-side, the attr form (§4's
    # conventions); the drain is card-side — each foundation's `on complete
    # labor` clause rolls the 30% employment risk (§6.18: CS's die, a
    # different referent) — and the `job` recipes bootstrap the wheel
    # (§9.48). First match wins (§6.4): work.frail outranks work.vigor (a
    # frail body labors ruined even with a living VIGOR bound beside it),
    # and work.post outranks work.senior on a world check — the two posts
    # share the one `post` marker aspect (the plan's G1 parenthetical), so
    # the senior's existence in the world is what disambiguates them.
    actors: 1 kind:character
    with: 0..1 kind:resource aspect:vigor>=1 | kind:resource aspect:wits>=1 | kind:resource aspect:yearning>=1 | kind:resource aspect:weary>=1 | kind:resource aspect:dim>=1 | kind:resource aspect:pale>=1 | kind:character aspect:bell_voice>=1 | kind:state aspect:frail>=1 | kind:item aspect:post>=1
    at: 0..1 kind:place
    duration: 1h
    recipes:
      work.frail when total(with, aspect:frail) >= 1 -> ROLL(1, 10), IF roll <= 3 -> (ENDING THE_BODY_FAILS) ELSE -> (SET(ACTORS, silver, +1), NARRATE "{actors} put the ruined body to work anyway, and the hour takes the wage it always takes. One silver, and the body's account runs shorter by more than that.")
      work.guest when total(with, aspect:bell_voice) >= 1 -> SET(ACTORS, silver, +3), NARRATE "{actors} keep the ledger open and let the guest do the reading. The foreman pays three silver and asks no questions; the fog, which heard the counting, asks none either."
      work.vigor aspects labor, job when total(with, aspect:vigor) >= 1 -> SET(ACTORS, silver, +1), ROLL(1, 10), IF roll <= 3 -> (SPAWN MENDING, NARRATE "An hour of honest lifting, and the body answers it: something knits that was not knitting before.") ELSE -> (NARRATE "An hour of honest lifting. The body holds, and the purse is one silver the heavier.")
      work.weary aspects labor when total(with, aspect:weary) >= 1 -> SET(ACTORS, silver, +1), ROLL(1, 10), IF roll <= 3 AND NOT exists(name:THE_FEVER) -> (SPAWN THE_FEVER, SET(THE_FEVER, expires, 3h), NARRATE "Work on a weary body is work on borrowed wax. By the end of the hour the borrowed part has caught.") ELSE -> (NARRATE "The weary hour earns its one silver and takes nothing it did not bring.")
      work.wits aspects labor, job when total(with, aspect:wits) >= 1 -> SET(ACTORS, silver, +2), ROLL(1, 10), IF roll <= 3 AND NOT exists(name:THE_CLERKS_POST) AND NOT exists(name:THE_SENIOR_POST) -> (SPAWN THE_CLERKS_POST, NARRATE "The count came out true three runs running, and the clerk's bench puts its post in writing. Two silver for the hour; the post pays better, and expects her by name.") ELSE -> (NARRATE "Two silver for the hour: figures, ledgers, fog. The arithmetic holds.")
      work.dim aspects labor when total(with, aspect:dim) >= 1 -> SET(ACTORS, silver, +1), NARRATE "{actors} work the dimmed wit like a bad lamp: it gives light enough to count by, and no more."
      work.yearning aspects labor, job when total(with, aspect:yearning) >= 1 -> SET(ACTORS, silver, +1), ROLL(1, 10), IF roll <= 3 -> (SPAWN GLIMMER, NARRATE "Somewhere in the routine — a handwidth of gilt on a ledger edge — the wanting catches the light, and for once does not let go.") ELSE -> (NARRATE "The yearning works the hour through and collects for it. It does not ask why.")
      work.pale aspects labor when total(with, aspect:pale) >= 1 -> SET(ACTORS, silver, +1), NARRATE "The pale yearning goes through the motions of an hour's work and collects for them. The motions do not notice the difference."
      work.post aspects job when total(with, aspect:post) >= 1 AND NOT exists(name:THE_SENIOR_POST) -> SET(ACTORS, silver, +3), ROLL(1, 10), IF roll <= 3 -> (REPLACE THE_CLERKS_POST WITH THE_SENIOR_POST, NARRATE "Three silver, and the bench's senior seat falls to her on a signature. The seal is still wet when the fog takes an interest in her name.") ELSE -> (NARRATE "Three silver for the clerk's hour. The bench keeps the seat it has, and her in it.")
      work.senior aspects job when total(with, aspect:post) >= 1 -> SET(ACTORS, silver, +4), NARRATE "Four silver for the senior hour. The desk has her name on it now, and the drawers know it."
      work.beg when NOT (exists(name:VIGOR) OR exists(name:WITS) OR exists(name:YEARNING)) -> ROLL(1, 10), IF roll <= 3 -> (SET(ACTORS, silver, +2), NARRATE "Empty-handed, she begs the fog's own parish, and the parish pays — two silver, and no name taken.") ELSE -> (SET(ACTORS, silver, +1), SPAWN DREAD, NARRATE "One silver, taken as charity. The taking of it sits in the chest like weather coming down.")
      work.default -> NARRATE "{actors} put in an hour, and the hour gives back what it will."

  WAIT:
    # the wheel. time.turn is the needs cycle plus the weather dispatch:
    # drain one silver (and feed — the hollow days give back the table),
    # else eat VIGOR into THE_HOLLOW_DAYS, else the body fails; then draw a
    # weather from the SEASONS deck and hand the cycle to that weather's
    # recipe as a RUN (§9.47 — one RUN reached per completion; the follow-up
    # rechains time.turn, and the loop stays resident exactly as CS's
    # needs → discardseason → drawseason → needs does). All eight weathers
    # rechain: a weather recipe never ends without its RUN except in a death
    # arm (the plan's §8/P5 pin). Selection order is load-bearing here: the
    # weather recipes and their judges are RUN targets (the §9.47 walk goes
    # by id, never by list position), but a plain player wait must keep
    # selecting time.turn once the wheel is resident — so time.turn sits
    # first and wait.default last (first match wins, §6.4) — and every RUN
    # target's when carries exists(name:THE_TURNING) so a pre-bootstrap wait
    # can never match one, with the rest of each when true at its hand-off
    # and distinct from its siblings (the lint's shadow check).
    actors: 1 kind:character
    duration: 1h
    recipes:
      time.turn when exists(name:THE_TURNING) -> IF actors.attr.silver >= 1 -> (SET(ACTORS, silver, -1), IF exists(name:THE_HOLLOW_DAYS) -> (DESTROY THE_HOLLOW_DAYS, NARRATE "The silver goes out for bread, and the hollow days give back the table they had made of the room.")) ELSE IF exists(name:VIGOR) -> (DESTROY VIGOR, SPAWN THE_HOLLOW_DAYS, NARRATE "No silver for the meal, so the body pays it itself. The hunger moves in and starts calling the room its own.") ELSE -> (ENDING THE_BODY_FAILS), DRAW SEASONS INTO ACTORS, IF exists(name:SEASON_GREY) -> (RUN "season.despair_link") ELSE IF exists(name:SEASON_WHITE) -> (RUN "season.rapture_link") ELSE IF exists(name:SEASON_SHADOW) -> (RUN "season.suspicion_link") ELSE IF exists(name:SEASON_AMBITION) -> (RUN "season.ambition") ELSE IF exists(name:SEASON_SICKLY) -> (RUN "season.sick") ELSE IF exists(name:SEASON_LEAN) -> (RUN "season.rags") ELSE IF exists(name:SEASON_WARM) -> (RUN "season.warm") ELSE -> (RUN "season.quiet")
      season.despair_link when exists(name:SEASON_GREY) -> DESTROY SEASON_GREY, RUN "despair_judge"
      despair_judge when exists(name:THE_TURNING) AND count(actors) >= 1 -> IF exists(name:EASE) -> (RUN "despair_abate") ELSE IF exists(name:DREAD) -> (RUN "despair_process") ELSE -> (NARRATE "The grey morning passes over the town like a hand over a lamp, and finds nothing of hers to take.", RUN "time.turn")
      despair_abate when exists(name:THE_TURNING) AND exists(name:EASE) -> DESTROY EASE, NARRATE "The ease goes to the grey exactly where the grey is thickest, and the morning thins where it was paid.", RUN "time.turn"
      despair_process when exists(name:THE_TURNING) AND exists(name:DREAD) -> DESTROY DREAD, SPAWN THE_GREY_MARK, NARRATE "The grey morning finds the dread and does what the town does with everything: it files it. Another mark goes into the grey water.", IF count(name:THE_GREY_MARK) >= 3 -> (NARRATE "The fog comes indoors. It knows the rooms; it has been reading the ledgers.", ENDING GREY_WATER) ELSE -> (RUN "time.turn")
      season.rapture_link when exists(name:SEASON_WHITE) -> DESTROY SEASON_WHITE, RUN "rapture_judge"
      rapture_judge when exists(name:THE_TURNING) AND count(actors) = 1 -> IF exists(name:RAPTURE) -> (RUN "rapture_process") ELSE -> (NARRATE "The white air rings through the town, clear and high, and passes one restorer's window without stopping.", RUN "time.turn")
      rapture_process when exists(name:THE_TURNING) AND exists(name:RAPTURE) -> DESTROY RAPTURE, SPAWN THE_BRIGHT_MARK, NARRATE "The white air finds the rapture and sets its seal on it. Another mark goes into the bright book.", IF count(name:THE_BRIGHT_MARK) >= 3 -> (NARRATE "A bell rings, one note too many. She answers it. Nobody else hears it, and that is the last thing that happens in the room.", ENDING BRIGHT_AIR) ELSE -> (RUN "time.turn")
      season.sick when exists(name:SEASON_SICKLY) -> DESTROY SEASON_SICKLY, IF exists(name:VIGOR) AND NOT exists(name:THE_FEVER) -> (REPLACE VIGOR WITH THE_FEVER, SET(THE_FEVER, expires, 3h), NARRATE "The sickly air goes through the body like a damp draft through a seal, and the fever moves in on a three-hour lease.", RUN "time.turn") ELSE IF exists(name:THE_WEARY_HOUR) AND NOT exists(name:THE_FEVER) -> (REPLACE THE_WEARY_HOUR WITH THE_FEVER, SET(THE_FEVER, expires, 3h), NARRATE "The sickly air finds the weary hour already sitting down, and finishes the job.
