# Ledger — engine deficiencies & bugs surfaced by the v0.6 CS slice

The owner's mandate: authoring the slice doubles as an engine audit. Every
phase's review adjudicates each friction point as ENGINE-BUG (engine violates
its own spec), ENGINE-GAP (spec-silent, blocks natural authoring),
FROZEN-QUIRK (spec pins it; content lives with it), or CONTENT-ERROR. Engine
BUG/GAP items get a disposition: FIX (queued/landed, with commit) / IDIOM
(documented authoring shape) / LINT (content tooling) / DOC-NOTE.

## Found in Phase A (foundations + season wheel)

- **E1 · ENGINE-GAP · missing attr compares as absent, not 0** —
  `Pred::Cmp` on a living card's numeric attr yields false when the entry is
  missing (`src/core/predicate.rs` Cmp eval, "either operand missing →
  false"), while §9.31 SET-delta semantics and `total()` both treat missing
  as 0. Spec §6.3 is silent on attr-path comparisons (§9.39 pins aspects
  only). Consequence: a `silver < cost` broke-gate cannot be authored
  correctly for a first-time buyer (script entities mint empty attrs), and no
  content workaround exists.
  **Disposition: FIX QUEUED** — living-card numeric attr reads read 0 when
  absent (behavior-preserving for every `>=`/`!=` gate in the two shipped
  scripts; `<` gates become correct).
- **E2 · ENGINE-GAP (minor) + IDIOM · RUN hand-off has no context binding** —
  §9.47 re-evaluates a candidate's `when:` against the post-outcome draft,
  and the shadow lint rejects identical whens, so every wheel dispatch target
  needed a synthetic world-marker when (`exists(name:THE_TURNING) AND …`,
  `count(actors) >= 1` vs `= 1` as lint noise). **Disposition: IDIOM** — the
  better content shape (keep the season card alive through its judge; judges
  gate on `exists(name:SEASON_…)`) lands with Phase B; doc note in the plan.
- **E3 · FROZEN-QUIRK · REPLACE refuses entities; trigger-body failure
  freezes the clock** — `REPLACE X WITH <entity>` refuses ("no kind",
  engine.rs REPLACE arm; §9.33 pins prototype successors), and a never-alive
  prototype inside a trigger body fails the whole advance pass forever
  (events have no window-refuse; §9.19/§9.32 severity). **Disposition:
  DOC-NOTE** (plan law 1 already pins DESTROY+SPAWN+SET restores) + future
  lint candidate.
- **E4 · FROZEN-QUIRK · silent chain death** — a weather with no matching RUN
  candidate ends the wheel with no diagnostic (§9.47's "that is CS's chain
  ending"). A content drift (rename, cardinality) would silently stop the
  seasons. **Disposition: LINT candidate** (warn on RUN-target whens with
  bare `count(role)` gates) + §8 doc note.
- **E5 · FROZEN-QUIRK (cosmetic) · follow-up rows render dead parent
  bindings** — a RUN follow-up's BEGIN row prints the parent's authored refs
  even when a bound card died mid-parent-window. **Disposition: DOC-NOTE.**
- **E6 · minor content-side input laxity** — bare clock input accepts hours
  > 23 (`0:118`) in the lenient parser. **Disposition: none** (lenient-input
  domain, pre-existing).
